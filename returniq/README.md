# ReturnIQ — Product Intelligence for Reducing E-Commerce Returns

> Predict → Explain → Intervene → Measure

ReturnIQ is an early-stage product prototype that helps merchandising, product, and operations teams identify which e-commerce orders and products are most likely to end in a return or cancellation, explain why, and evaluate interventions before rolling them out.

**Status: in development.** The full project (ML pipeline, FastAPI backend, React dashboard, intervention simulator, experiment design, tests, and documentation) will be published here shortly. This page will be replaced by the complete README with real, reproducible metrics.

## Planned scope

- Real public e-commerce data (UCI Online Retail II), with an honest, documented target definition
- Leak-free, chronologically split ML pipeline comparing multiple models
- Explainable per-order risk predictions
- Product intelligence and intervention simulator with clearly labeled assumptions
- Hypothetical A/B experiment design (a design artifact, not a claimed result)

**Stack:** Python, scikit-learn, FastAPI, SQLAlchemy, SQLite, React, TypeScript, Tailwind CSS, Recharts
